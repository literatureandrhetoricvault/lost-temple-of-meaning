# The Lost Temple of Meaning

A self-contained AP Literature setting-analysis adventure game for GitHub Pages.

## Deploy
Upload the contents of this folder to a GitHub Pages repository. `index.html` is the entry point and `.nojekyll` is included.

## Progress saving
Student progress is stored in the browser's localStorage on the same browser/device. The final report records **first-attempt accuracy** for academic questions. Adventure-runner performance is reported separately and never affects academic accuracy.


## Adventure treasure system
Each non-academic runner lasts 45 seconds. Students can capture three treasures during each run: one at 15 seconds, one at 30 seconds, and the final treasure at the 45-second finish. Across six adventure sequences, up to 18 treasures can be captured. Treasure totals are reported separately and never affect academic accuracy.
